## Cấu trúc thư mục

### 1. [ux-exercise](./ux-exercise/) - Bài tập phân tích UX
Khảo sát và mổ xẻ trải nghiệm người dùng đối với: **MoMo — Moni AI Assistant** (Trợ lý phân loại chi tiêu).
Bài tập phân tích chi tiết ứng dụng MoMo Moni dựa trên **4 thiết kế đường dẫn (4 Paths)**:
- **Path 1:** Khi AI đúng.
- **Path 2:** Khi AI không chắc chắn.
- **Path 3:** Khi AI sai.
- **Path 4:** Khi User mất niềm tin và cần hỗ trợ từ con người (Fallback).

**Tài liệu:**
- [`analysis.md`](./ux-exercise/analysis.md): Bản phân tích chi tiết các tình huống và đánh giá path tốt nhất/yếu nhất.
- [`sketch.pdf`](./ux-exercise/sketch.pdf): File sketch minh họa liên quan đến phân tích.
